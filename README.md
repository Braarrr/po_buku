# PO Buku - C

Program sederhana untuk menghitung total pembelian buku
dengan beberapa pilihan mata uang.

## Features

- Input jumlah buku
- Input judul buku
- Pilihan currency USD, Pound, SGD, dan Euro
- Konversi harga ke IDR
- Perhitungan ongkir tetap Rp15.000
- Receipt pembelian
- Penyimpanan history transaksi
- Hapus history transaksi

## Concepts Used

- Variable
- Array
- Function
- Loop
- If/else
- Switch case
- Pointer
- Input validation

## How to Run

Compile:

```bash
gcc po_buku.c -o po_buku
